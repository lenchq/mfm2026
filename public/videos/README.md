# Видео направлений

Поместите актуальное видео дизайна в `public/videos/design.mp4`.
Vite отдаёт его по адресу `/videos/design.mp4` в dev-режиме и копирует в `dist/videos/` при сборке.

Первая карточка направления «Дизайн» открывает это видео. Файл загружается только при нажатии на карточку. Рекомендуемый формат для мобильных браузеров: MP4, H.264 + AAC.

Остальные карточки открывают полноэкранную заглушку. Самого видеофайла в исходном проекте на момент реализации нет.
