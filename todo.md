# ТЕХНО5 — ТЗ и план разработки

## Источники
- `dsa.rtf`.
- `codex-session-01a0a479-8922-79b0-b996-e131514e9bae.md`.
- Требования из сессии: Vite + Tailwind CSS, изображения с placehold.co.

## Цель и структура
Образовательная платформа: выбрать профессию → познакомиться через короткие видео → изучить маршрут → выполнять практику → общаться с сообществом.

В главном меню только Главная, Карта обучения, Форум.
- `/`: hero, три направления, четыре шага обучения, финальный CTA.
- `/karta-obucheniya?track=…`: переключение направлений, четыре этапа каждого маршрута, теория и практика, итоговый проект.
- `/napravleniya/dizayn`
- `/napravleniya/ai-i-big-data`
- `/napravleniya/robototehnika-i-bpla`
- `/forum?track=…`: демонстрационная лента обсуждений, категории и популярные темы.

Страницы направлений содержат информацию о профессии перед видео, примеры работодателей и переход к соответствующей карте. Карточки видео листаются горизонтально; на мобильном видна одна карточка. Нажатие открывает полноэкранный диалог, первое видео дизайна загружается из `/videos/design.mp4`, остальные показывают заглушки. Работодатели не объявляются партнёрами; стажировки и вакансии не подтверждены.

Визуальный стиль: бежевый фон, крупные прописные заголовки, белые карточки, синие и оранжевые акценты, нумерация. Теория — синяя, практика — оранжевая, проект — зелёный. Фото-заглушки загружаются с placehold.co.

## Файлы
- `src/data.js` / `src/data.en.js` — направления, учебные темы, примеры обсуждений на русском / английском.
- `src/i18n.js` — словарь интерфейса, выбор и сохранение языка.
- `src/companies.js` — соответствие компаний и файлов логотипов.
- `src/localization.css` — переключатель языка и адаптивная лента логотипов.
- `src/main.js` — шаблоны страниц, маршрутизация, взаимодействия.
- `src/style.css` — Tailwind и общий адаптивный визуальный слой.
- `src/features.css` — схема roadmap, видеолента и её мобильная адаптация, полноэкранный диалог.
- `src/videos.js` — карточки, загрузка видеоплеера по нажатию, запуск квиза после завершения.
- `src/quiz-data.js` — вопросы и объяснения из референсов на двух языках.
- `src/quiz.js` / `src/quiz.css` — сценарий квиза и оформление карточек.
- `tests/quiz-data.test.js` — тесты структуры карточек и соответствия локализаций.
- `src/materials.js` — примерные названия материалов и неактивные ссылки.
- `public/videos/README.md` — инструкция по размещению MP4.
- `index.html` — точка входа, язык, метаданные.

## Запуск
```sh
npm install
npm run dev
npm run build
npm run preview
```

Квиз визуально проверен в Chrome на мобильном и десктопном размерах. Полная проверка всех страниц и реального воспроизведения на iOS/Android остаётся в плане. Для обложек-заглушек требуется доступ к placehold.co; фотографии главной и логотипы загружаются локально. Прогресс не синхронизируется между устройствами.
